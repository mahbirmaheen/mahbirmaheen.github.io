# Mahbir Ahmed Maheen | Personal Portfolio & Research Hub 🔬

Welcome to the source code for my personal portfolio website! 

I am an undergraduate researcher in Materials and Metallurgical Engineering at Bangladesh University of Engineering & Technology (BUET). My research focuses on bridging theoretical physics and machine learning to drive the discovery of advanced semiconductor, electronic, and eco-friendly solar materials.

🌐 **Live Website:** [mahbirmaheen.github.io](https://mahbirmaheen.github.io/)

## 🚀 Key Features of this Website

* **Custom Scientific Plotter (`graph.html`):** A built-in, fully responsive graphing engine using Plotly.js. It allows users to upload CSV/Excel datasets and calculate spline, linear, polynomial, and logarithmic regressions natively in the browser.
* **Research & Publication Showcase:** Dedicated, styled manuscript layouts for my publications, including my work on *Lead-Free Halide Perovskites via Physics-Informed Machine Learning*.
* **Smooth GPU-Accelerated Animations:** Custom-built `IntersectionObserver` JavaScript for lag-free scroll reveals, dynamic hover states, and smooth navigation rendering.
* **Fully Responsive UI:** Custom CSS flexbox and grid layouts optimized for desktop, tablet, and mobile viewing without relying on heavy frameworks.

## 🛠️ Tech Stack

* **Frontend:** HTML5, CSS3 (Custom Variables, Grid/Flexbox), Vanilla JavaScript
* **Libraries (for Scientific Plotter):** * [Plotly.js](https://plotly.com/javascript/) (Graph Rendering)
  * [PapaParse](https://www.papaparse.com/) (CSV Parsing)
  * [SheetJS / xlsx](https://sheetjs.com/) (Excel Parsing)
  * [Regression.js](https://github.com/Tom-Alexander/regression-js) (Curve Fitting)
  * [MathJax](https://www.mathjax.org/) (LaTeX Mathematical Rendering)
